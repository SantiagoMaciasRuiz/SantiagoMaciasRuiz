### 🚀 Sobre mí

Estudiante de Ingeniería de Sistemas en la **Universidad Nacional de Colombia**, especializado en diseñar, construir y optimizar sistemas orientados a datos. Conecto la arquitectura backend con la infraestructura de datos para convertir fuentes distribuidas y heterogéneas en activos de producción, pipelines automatizados y soluciones analíticas.

- 📈 **Data Engineering:** modelado relacional, ETL/ELT, calidad de datos y automatización.
- ⚙️ **Backend:** APIs, scripts modulares, integración de servicios y lógica escalable.
- 🧠 **Analytics Engineering:** indicadores territoriales, dashboards y modelos analíticos con Power BI y DAX.
- 🛡️ **Calidad:** manejo de errores, logging, pruebas y diseño mantenible.
